# 简历生成器 | Resume Generator

一个帮助用户快速生成专业简历的在线工具。

## 功能特性

- 📝 **信息填写** - 左侧表单填写简历信息，右侧实时预览
- 🎨 **3套模板** - 简约模板、技术风模板、商务模板
- 📄 **PDF导出** - 一键导出标准A4简历
- 📱 **响应式布局** - PC和手机都能使用
- 💾 **本地存储** - 数据自动保存到浏览器
- 📜 **修改记录** - 实时记录每次修改操作

## 技术栈

- React 18 + Hooks
- Tailwind CSS
- Vite
- jsPDF + html2canvas

## 项目故事

### 为什么做这个项目

学完React基础之后，想做一个实际有用的项目练手。当时正好在找工作，就想着做一个简历生成器自己用，顺便练一下前端技术。

### 第一版（很丑）

一开始用的是Vue2 + Element UI，照着网上的后台管理模板抄的。做了大概两周，页面丑不说，代码也全写在一个.vue文件里。功能只有一个——填完表单直接展示，连模板切换都没有。

最关键的是没有PDF导出功能，生成完简历还得截图，截图还得用PS拼成A4大小，特别麻烦。

### 问题发现

1. **界面丑**：Element UI默认样式跟网上那些简历网站比差太远
2. **不能下载**：只能看，不能导出PDF
3. **代码混乱**：全写在一个文件里，组件没拆分

### 修改过程

**第一阶段：换技术栈（1周）**

把Vue2换成React，样式从Element UI换成Tailwind CSS。这个阶段主要踩的坑是不熟悉React的hook写法，useState和useEffect搞混了好几次。

后来发现Tailwind的响应式类特别方便，1/2这种写法直接就能适配不同屏幕。

**第二阶段：加模板切换（3天）**

做了3套模板：简约版、技术风、商务版。

切换模板的时候遇到一个问题：不同模板要显示的字段不一样。比如商务版多了一个"自我评价"字段，简约版就没有。

一开始想的是用if-else判断，后来改成用配置文件管理每个模板的字段列表，这样改起来方便很多。

```javascript
const templateConfigs = {
  simple: { showSelfAssessment: false, showGPA: false },
  business: { showSelfAssessment: true, showGPA: false },
  tech: { showSelfAssessment: false, showGPA: true }
}
```

**第三阶段：PDF导出（踩坑最久）**

一开始用的html2canvas转图片再转PDF，中文显示有问题，字体发虚，还有些字直接变成方块。

后来换成jsPDF，用代码直接生成PDF排版。中文需要加载中文字体包，这个也是试了好几个才找到能用的。

还有一个问题是长简历分页。如果内容超过一页，需要自动分页。解决方法是在导出前先计算每个模块的高度，超了就分到下一页。

```javascript
// 伪代码
if (currentY + moduleHeight > pageHeight) {
  pdf.addPage()
  currentY = 0
}
```

**第四阶段：响应式适配（半天）**

一开始只做了PC端，手机上打开乱成一团。后来用Tailwind的响应式类做了适配：

- PC端：左右分栏，表单和预览并排
- 手机端：单列，先填表单再预览

这个改动不大，Tailwind的响应式类很好用。

### 最终结果

- ✅ 3套模板可选：简约、技术、商务
- ✅ PDF导出正常，中文显示正常
- ✅ 响应式布局，PC和手机都能用
- ✅ 代码拆分合理：表单组件、预览组件、模板组件分开
- ✅ 实现了修改记录功能，每次操作都能看到

### 用户数据

- **内测用户**：找了10个同学帮忙测试
- **反馈最多的问题**：刚开始不知道表单怎么填，后来加了placeholder提示就好多了
- **使用场景**：大部分是用来生成秋招/春招简历
- **导出的PDF**：大约70%用户能直接用，30%会再调整一下格式

### 踩过的坑

| 问题 | 解决方法 |
|------|---------|
| React hook不熟 | 看官方文档和开源项目，照着改 |
| 中文PDF乱码 | 换成jsPDF，加载中文字体包 |
| 长简历分页 | 计算模块高度，超出自动分页 |
| 模板字段不统一 | 用配置文件管理每个模板的字段 |
| 响应式布局麻烦 | 用Tailwind的响应式类，1/2写法 |

- Section.jsx - 表单区块
- Input.jsx - 输入框组件
- ResumePreview - 简历预览
