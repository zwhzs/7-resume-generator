# 简历生成器 | Resume Generator

一个帮助用户快速生成专业简历的在线工具。

## 功能特性

- 📝 **信息填写** - 左侧表单填写简历信息，右侧实时预览
- 🎨 **4套差异化模板** - 简约、侧边栏、时间线、专业风格
- 📄 **PDF导出** - 一键导出标准A4简历
- 📱 **响应式布局** - PC和手机都能使用
- 💾 **本地存储** - 数据自动保存到浏览器
- 📜 **修改记录** - 实时记录每次修改操作
- ⬆️ **模板上传** - 支持上传自定义HTML模板

## 技术栈

- HTML5 + CSS3
- JavaScript (原生)
- jsPDF + html2canvas

## 项目故事

### 为什么做这个项目

学完前端基础之后，想做一个实际有用的项目练手。当时正好在准备简历，就想着做一个简历生成器，可以实时预览和导出PDF。

### 开发历程

**第一版：基础功能搭建**

- 实现表单填写和实时预览
- 添加PDF导出功能（使用jsPDF + html2canvas）
- 支持本地存储，刷新页面数据不丢失

**第二版：模板系统重构**

- 精简模板数量，从8个删减为4个差异化模板
- 所有模板统一采用中文风格排版
- 头部统一显示"个人简历"，移除此前的emoji图标和英文副标题
- 修复模板重复显示姓名的问题

**模板详情：**

| 模板名称 | 风格特点 | 适用场景 |
|---------|---------|---------|
| 简约 | 极简线条风格，居中大标题 | 通用场景 |
| 侧边栏 | 左侧简洁分栏，透明背景 | 技术岗位 |
| 时间线 | 左侧竖线时间轴，绿色主题 | 经历丰富的岗位 |
| 专业 | 商务卡片风格，蓝色主题 | 正式商务岗位 |

**第三版：细节优化**

- **侧边栏模板优化**：去掉深色背景框，改为透明简洁风格
- **字体管理简化**：删减冗余选项，保留常用中文字体
- **修复重复问题**：侧边栏模板不再重复显示姓名和联系方式
- **模板上传功能**：支持用户上传自定义HTML模板

**第四版：样式统一**

- 统一中文排版风格，采用网格布局展示基本信息
- 优化区块标题样式，使用背景色块或左侧边框区分
- 修复时间线模板的时间轴显示
- 统一配色方案（绿色 #4a7c59 + 金色 #c4a35a）

### 踩坑记录

**1. 中文PDF导出乱码**

使用html2canvas转图片再生成PDF时，中文字体显示异常。

解决方法：使用jsPDF的`html()`方法直接生成，确保HTML中指定了中文字体（如宋体、黑体）。

**2. 模板差异化设计**

一开始模板之间差异太小，用户无法区分。

解决方法：重新设计每个模板的视觉风格：
- 简约模板：极简线条，无多余装饰
- 侧边栏模板：左右分栏，简洁背景
- 时间线模板：竖线时间轴，里程碑标记
- 专业模板：卡片式布局，商务蓝色调

**3. 信息重复显示**

侧边栏模板同时显示侧边栏信息和基本信息区块，导致姓名、联系方式重复。

解决方法：为侧边栏模板单独处理基本信息区块，只显示性别和年龄。

**4. 响应式布局**

PC端左右分栏，手机端需要自适应。

解决方法：使用CSS Grid和Flexbox，配合媒体查询实现响应式。

### 最终结果

- ✅ 4套差异化模板，覆盖不同场景需求
- ✅ PDF导出正常，中文显示完美
- ✅ 响应式布局，PC和手机都能正常使用
- ✅ 支持自定义模板上传
- ✅ 代码结构清晰，易于维护

## 使用说明

1. 在左侧表单填写个人信息、教育背景、工作经历等
2. 右侧实时预览简历效果
3. 选择喜欢的模板风格（简约/侧边栏/时间线/专业）
4. 点击"导出PDF"下载简历

## 本地运行

```bash
# 进入项目目录
cd 7-resume-generator

# 启动本地服务器
python -m http.server 8080

# 浏览器访问 http://localhost:8080
```
